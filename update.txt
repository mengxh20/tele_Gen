## 2026-04-16 | 当前压缩恢复主链路基线

- Date: `2026-04-16`
- Version Title: 当前压缩恢复主链路基线
- Mainline Changes:
  - 项目主线聚焦 Helios VAE latents 的低码率压缩、传输与恢复，不以通用视频生成为默认目标
  - `reconstruct/recover.py` 统一承担 recover 训练与压缩恢复推理
  - 推理链路固定为 `clean latents -> low codec payload / low_full_latents -> stage1 recover -> low_latents / recover_latents / metrics`
- Affected Entrypoints/Artifacts:
  - Training entry: `scripts/training/train_recover_ddp.sh`
  - Inference entry: `scripts/inference/infer_recover_ddp.sh`
  - Runtime mainline: `reconstruct/recover.py`
  - Latent preparation: `reconstruct/encoder.py`
  - Verification/export helper: `reconstruct/decoder.py`
  - Stable artifacts: `transformer_full.pt`、`recover_config.json`、`train_metrics.json`、`low_latents/`、`recover_latents/`、`metrics/`
- Compression-Recovery Impact:
  - 主线验证重点转为 low bitrate baseline 与 recover 结果的对比，默认围绕码率效率、恢复误差、时序连续性和边界过渡质量展开
  - 视频解码导出主要用于可视化、验收和对比，不替代 latent 压缩恢复主链路本身
- Compatibility Notes:
  - 项目记忆以 `reconstruct/` 当前实现及其训练/推理入口为准，而不是以上游 Helios README 的通用生成描述为准
  - 后续凡是主链路、默认 codec 路径、关键入口、产物格式、`recover_config` 兼容关系或关键指标语义发生重大变化，都必须在本文件追加记录

## 2026-04-16 | Recover 稳定性与无损验收增强

- Date: `2026-04-16`
- Version Title: Recover 稳定性与无损验收增强
- Mainline Changes:
  - `recover_config` 升级到 `helios_recover_v7`
  - recover 训练新增 `recover_condition_mode`，支持用真实 bitstream 解码后的 `low_full_latents` 作为恢复条件输入
  - recover 训练新增 `boundary_transition_loss` 与 `last_tail_recon_loss`，加强 section 边界和最后一个 tail latent 的稳定性约束
  - 推理新增 `section_seed_mode` 与 CLI 级 `fix_anchor_during_denoise` / `initialize_anchor_from_low` 覆盖
  - `decoder.py` 新增无损 `ffv1` 导出，默认验收输出不再依赖有损 H.264 mp4
- Affected Entrypoints/Artifacts:
  - Training entry: `scripts/training/train_recover_ddp.sh`
  - Inference entry: `scripts/inference/infer_recover_ddp.sh`
  - Runtime mainline: `reconstruct/recover.py`
  - Verification/export helper: `reconstruct/decoder.py`
  - New config fields: `recover_condition_mode`、`boundary_transition_loss_weight`、`last_tail_recon_loss_weight`
  - New inference metadata: `section_seed_mode`
  - Default verification export: `Videos/*.mkv` and `duibi_Videos/*.mkv` when using default decoder settings
- Compression-Recovery Impact:
  - 不改变 `1 anchor + 2 tail` 的默认低码率结构，优先通过恢复约束与推理稳定性降低伪影和闪烁
  - 训练条件更贴近真实压缩-传输-恢复链路，减少 train/infer low-latent 分布偏差
  - 视频验收默认转为无损导出，降低展示层对闪烁和伪影的放大
- Compatibility Notes:
  - `load_recover_config` 兼容 `helios_recover_v2` 到 `helios_recover_v7`
  - 旧 checkpoint 未包含的新损失权重默认回退为 0 或当前默认值，不阻断推理
